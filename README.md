# Snacky Dash: Food Maze Puzzle Solver

A Python project to build, solve, and train an AI agent on a food-maze puzzle game.

## Project Stages

* Engine of the game
* Deterministic solver
* Reinforcement learning solution

## Project Structure

* `levels/` - Stores level design configurations and layout files.
* `src/snacky_dash/` - Core package containing the game engine, deterministic pathfinder, and RL solver models.
* `tests/` - Automated unit and integration tests for core logic.

## Setup

1. Create a virtual environment:

```bash

```

2. Activate the virtual environment

* On Windows

```bash

```
